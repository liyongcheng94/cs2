# CS2HQ — 专属 CS2 提升平台（D:\project\cs2）（v5 终版，评审结案）

## Context（为什么做）

用户是完美平台 CS2 玩家（高敏 eDPI≈1000+ / OMR248 鼠标 / 主玩 Dust2 / 狙击A级·残局B级强项，突破·补枪·道具 C级短板——来自 DeepSeek 对话历史还原）。目前的提升闭环全靠手动。目标：**自动化闭环——战绩自动拉、demo 自动析、失误自动总结、教学视频自动学、道具自动建卡，全部沉淀到 MindVault 公网可查**，Web 面板 + ZCode skills 双入口。

## 已确认决策（4 轮提问 + 三轮技术评审结案）

1. Web 面板首版；2. 四能力全做；3. 完美平台手动 token 主 + 浏览器自动化兜底；4. 道具卡自动抽取；5. 独立项目 + MCP 推送；6. MindVault 基座栈（FastAPI+SQLModel+SQLite / React+antd+Vite / TDD+BDD）；7. demo 四维分析首版全做；8. 全自动入库；9. 时刻视频压缩≤20MB + MindVault 加 /api/capture/videos；10. AI 复用 MindVault 模式；11. 首版带 ZCode skills（极简版随阶段 2）；12. 项目名 CS2HQ；13. B站 ASR 首版砍掉（无字幕标 no_subtitle 跳过）。

## 关键事实（调研结论）

- **MindVault 写入通道**：MCP `POST /api/mcp` 只有 create 无 update（`api/mcp.py:39-78`）；REST 有 `PUT /api/items/{uuid}`；auth 经 `/api/auth/login` 换 Bearer；公网 Cloudflare Quick Tunnel（`--protocol http2`）；blobs `GET /api/blobs/{path}`，上传限 20MB。
- **完美平台**：token 取自 partner.wmpvp.com cookie（与 mySteamId 1:1，登录轮换）；`POST api.wmpvp.com/api/csgo/home/match/list` + `/api/csgo/home/pvp/detailStats`（头：token + appversion:3.5.4.172 + platform:android）；demo 签名 URL 会过期；完美时刻 `acty/community/moments/getPersonalMoments` 返回 mp4 直链。**禁止 PWHook 注入（封号风险）**。
- **B 站**：检索需 WBI 签名 + buvid3 引导；字幕必须走 `/x/player/wbi/v2`（需 SESSDATA）；风控码 -412/-352/10031/12051/12015；个人低频抓取、限速 1s。
- **demo 解析候选**：demoparser2（OOP）vs awpy（Polars 向量化）——spike 实测定选，必测 30min demo 耗时/峰值内存。

## 实施计划（按阶段，每阶段有验证闸门）

### 阶段 0：基座 + MindVault 视频端点 + Mock 全链路（1 天）
- backend/（FastAPI+SQLModel+SQLite）+ frontend/（React+antd+Vite）+ AGENTS.md（TDD+BDD）+ git/分支如上 + loguru + 依赖锁版。
- 表结构：matches / match_stats / demo_analyses(JSON 四维) / clips / bili_videos / grenade_cards / reports / player_profile / settings / tasks(含 priority)。数据访问收敛 services 层；AGENTS.md 记录迁 PostgreSQL 预案。
- **凭证加密**：token/SESSDATA 用 `cryptography.fernet` 加密存 settings 表；secret.key 走环境变量 + .gitignore。
- demo_analyses/reports JSON schema 首日定型（四维基线指标全字段预留，null 允许）。player_profile 预置 DeepSeek 画像种子。
- **MindVault 加 `POST /api/capture/videos`**（≤20MB → blobs `{source_hash}_{preset_hash}` 寻址 → type=video 条目）：写 blobs 原子化（.tmp → os.rename）；已存在且大小一致 → 直接返回既有元数据；走 MindVault TDD 流程。
- **Mock 全链路优先**：假数据跑通 后端→面板→复盘→MCP 推送→MindVault 可搜；提供 `POST /api/test/mock-flow`。
- **前端状态同步**：React Query/SWR 轮询 `GET /api/tasks`（5s），success 自动刷新列表。
- 覆盖率基线：首测值 -5% 写入 AGENTS.md。
- 闸门：pytest 绿 + tsc 过 + MindVault 新端点绿 + Mock 全链路（verify.bat 内 `curl -X POST .../api/test/mock-flow`）走通。

### 阶段 1：完美平台数据链路（1 天）
- `services/wanmei.py`：httpx；match/list 分页幂等 UPSERT；detailStats 存 match_stats；限速 ≥2s；**请求/响应全程 loguru trace（matchId 字段）**。
- Token 优雅退场：设置页“快速更新 Token”粘贴即存（加密）即时生效；401/403 立即熔断 → NEED_AUTH，严禁后台重试，面板红色横幅。
- scheduler 错峰：平台同步每 2h、demo 解析凌晨批量、B 站限白天、周报周日（按 priority）。
- 面板：对局列表 + 数据总览。
- 闸门：真凭证拉 ≥1 页对局不重复；手动失效 token 验证 NEED_AUTH。

### 阶段 2：demo 解析 + AI 复盘（2.5 天，核心）
- **Day 1 上午 spike（双基准）**：demoparser2 vs awpy 跑同一真实 demo，测 API 体验 + 30min demo 耗时/峰值内存；按需提取（对枪只抓 player_death、道具只抓 grenade_throw+player_blind、劣势枪位只抓死亡前 1s 坐标+Yaw/Pitch）；仍慢按回合分块。结论落 docs/。
- **CPU 任务隔离**：demo 解析与 ffmpeg 一律 `asyncio.to_thread()`/进程池，Semaphore(1) 串行防 OOM，不卡事件循环。
- `services/demo_dl.py`：签名 URL 下载；失败 5s 重试 1 次 → 仍败标 pending_demo 交下轮凌晨批量；解析产出 JSON 后立即删 raw demo（磁盘 GC）；解析耗时/内存 trace 日志。
- `services/demo_analysis.py`：四维解析按 schema 产出 JSON。
- `services/report.py`：Pydantic ReviewOutput 校验（失败重试 1 次 → 纯文本降级标注）；防幻觉证据链（每个失误必须引用 JSON 具体字段，无支撑宁可“无明显失误”）；今日唯一重点双轨制（Rule-based 硬红线优先，如 <5m 胜率<30% → “近战急停”；无红线才由 AI 证据链内选择）；关闭思考模式。
- **推送幂等**：source_hash = hash(matchId + prompt_version)；前置查重 → 已存在走 REST `PUT /api/items/{uuid}` 更新，新报告走 MCP create_note；提示词迭代出 v2 新笔记。
- **极简 /cs2-daily skill** 随本阶段末上线。
- 闸门：真实 demo → 四维 JSON → 面板可看 → 复盘过校验 → MindVault 可搜；坏输出验证降级；spike 数据落 docs/。

### 阶段 3：B 站视频管线 + 道具卡（1 天）
- `services/bili.py`：关键词 WBI 检索 / 手动 BV / UP 主订阅；仅字幕路线，无字幕标 no_subtitle 跳过；限速 1s；trace 日志。
- 风控软着陆：-412/-352 等 → 暂停对应 UP/关键词任务 ≥1h + 面板提示可切手动 BV。
- AI 总结（核心要点/适用段位/值得练的道具清单）+ 道具卡抽取（地图/点位/投掷物/站位/时机/时间戳，Dust2 优先）。
- 面板：视频总结列表 + 道具库（筛选 + 时间戳跳转）。
- 闸门：真实 BV → 总结 → ≥1 张道具卡 → MindVault 可搜。

### 阶段 4：完美时刻（1 天）
- `services/moments.py`：getPersonalMoments → mp4 下载 → ≤20MB 直接推，否则 ffmpeg `-preset veryfast` 压缩（720p/CRF28）→ MindVault /api/capture/videos → type=video 条目 + AI 一句话总结；推送成功后本地仅留缩略图或删除。
- 闸门：≥1 条真实时刻公网可看可播。

### 阶段 5：可视化增强 + 整合收口（1 天）
- ECharts：对枪矩阵热力图（X=距离分桶，Y=武器，色深=胜率）；死亡还原 2D 雷达散点图——游戏坐标→像素映射 + 纯地图底图；>100 点加 large:true。
- 完整版 skills：/cs2-review、/cs2-learn、/cs2-moments。
- 周报周日推送；scheduler 错峰全量启用；定时磁盘 GC；cf-tunnel 公网 + 密码访问。
- **verify.bat**：pytest + tsc + Mock 链路检查；每天收工前跑。
- 闸门：公网 URL 全流程走通；verify.bat 全绿。

## 禁区与回滚（deepintask 四件套）

- **禁区**：不做客户端注入；不批量爬 B站、不公开端点文档；凭证加密不进 git；不改 MindVault 除 capture/videos 外代码；完美平台限速 ≥2s、401/403 必熔断。
- **回滚**：demo 下载失败 → pending_demo 下轮重试；解析失败/超内存 → 降级仅 API 数据复盘；模型输出非法 → 重试 1 次 → 纯文本；无字幕 → no_subtitle 跳过；时刻压缩后仍超限 → 封面+链接卡片。
- **人工接管点**：token 失效（NEED_AUTH 熔断）、B 站风控暂停 ≥1h、完美平台接口变更（暂停 loop + 面板报警）。

## 验证方式（端到端）

1. pytest --cov-fail-under=<基线-5%> 全绿；前端 vitest + tsc 过。
2. Mock 链路：假数据面板→MindVault 公网全通，verify.bat 内置。
3. 真凭证端到端：同步 → demo → 四维解析 → 复盘 → 推送 → `curl http://127.0.0.1:8300/api/search?q=复盘` 命中 → 隧道公网可访问；同 hash 重复推送走 REST 更新。
4. B站/时刻/skills 各按阶段闸门验证。
5. spike 基准（30min demo 耗时/峰值内存）落 docs/ 作回归参照。

## 主要风险

1. B 站风控 → 软着陆（暂停 ≥1h + 手动 BV 兜底）。2. demo 解析耗时/内存 → 按需提取 + 分块 + Semaphore(1) + 仅 API 数据兜底。3. token 轮换 → NEED_AUTH 熔断 + 快速更新 + Fernet 加密。4. 磁盘膨胀 → 解析后删 raw、上传后删本地、定时 GC。

预计总工期 5-6 天；每阶段结束交付可验收物。开工顺序：ARCHITECTURE.md 落库 → git init + feature/phase-0-base → Mock UI 先行 → 啃完美平台与 demo 硬骨头。
